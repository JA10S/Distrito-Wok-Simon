# Restaurante Distrito Wok Simón

Menú digital para restaurante de comida oriental colombiana.

## 📁 Estructura del proyecto

```
restaurante/
├── src/
│   ├── menu.html              # Código fuente del menú
│   ├── styles/                # Archivos CSS
│   └── assets/                # Imágenes y recursos
├── docs/
│   ├── MENU_RESTAURANTE.md    # Documentación del menú
│   └── INGREDIENTES.md        # Lista de ingredientes
├── dist/                      # Archivos generados (PDF)
├── scripts/                   # Scripts de automatización
├── config/                    # Configuraciones
├── .gitignore                 # Archivos excluidos de Git
├── AGENTS.md                  # Contexto para IA
└── README.md                  # Este archivo
```

## 🚀 Comandos disponibles

```batch
# Ver resumen del proyecto
restaurante.bat

# Regenerar PDF
.\generar-pdf.ps1

# Ver harnes del proyecto
.\restaurante-harness.ps1
```

- **HTML5:** Estructura del menú

- Diseño responsivo para móviles
- 2 páginas A4 (210mm x 600mm)

- Integración con Google Drive
